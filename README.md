# School Academics Management System

A backend application for managing student academic information.

## Features

- Add students
- View student details
- Update student information
- Delete student records
- REST API endpoints
- Database integration

## Tech Stack

- Node.js
- Express.js
- MongoDB
- JavaScript

## API Endpoints

GET    /students
POST   /students
GET    /students/:id
PUT    /students/:id
DELETE /students/:id

## How to Run

npm install
npm start
